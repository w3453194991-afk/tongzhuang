# 部署到云服务器

把「小满童装 · 选款与报价中台」放到一台云服务器上，客户和员工在任何电脑用浏览器打开同一个网址，
看到的是**同一份数据**（询价、报价、结算单、售后都在服务器上）。

适合：阿里云 / 腾讯云 / 华为云的 Linux 服务器（Ubuntu / Debian / CentOS 都行）。
不需要域名、不需要备案也能先用起来——直接用 `http://公网IP:8765` 访问。

---

## 一、服务器要什么配置

| 项目 | 要求 |
|---|---|
| CPU / 内存 | 1 核 1G 就够（就是个 Node 静态服务 + JSON 存储） |
| 系统 | Ubuntu 20.04+ / Debian 11+ / CentOS 7+ |
| Node.js | **18 或更高**（服务端用了内置 fetch） |
| 磁盘 | 10G 起，数据存在 `data/store.json`，很小 |

> 已有的 2 核 2G 服务器完全可以和别的项目共用，只要端口不冲突。

---

## 二、把代码传上去

**方式 A：用 git（推荐，以后更新一条命令）**

```bash
ssh root@你的服务器IP

# 装 git 和 node
apt update && apt install -y git curl
curl -fsSL https://deb.nodesource.com/setup_18.x | bash -
apt install -y nodejs
node -v      # 应该显示 v18.x 或更高

# 拉代码
git clone https://github.com/w3453194991-afk/tongzhuang.git /opt/xiaoman
cd /opt/xiaoman
```

如果服务器在国内拉 GitHub 慢，可以在**本地电脑**这样做：

```powershell
# 本地 Windows：打成一个包
cd "E:\湖北\tongzhuang"
tar --exclude=.git --exclude=data -czf xiaoman.tar.gz .
```

然后用宝塔面板 / WinSCP / `scp xiaoman.tar.gz root@服务器IP:/opt/` 上传，
在服务器上 `mkdir -p /opt/xiaoman && tar -xzf xiaoman.tar.gz -C /opt/xiaoman`。

**方式 B：宝塔面板**

1. 面板里「文件」→ 进入 `/www/wwwroot` → 新建目录 `xiaoman` → 上传 zip 并解压
2. 「网站」→ 添加站点，PHP 版本选「纯静态」
3. 站点目录指向 `/www/wwwroot/xiaoman`
4. 后面用「Node 项目」或 SSH 跑服务即可

## 三、先跑起来看看

```bash
cd /opt/xiaoman
HOST=0.0.0.0 PORT=8765 node tools/server.js
```

看到这几行就成功了：

```
  小满童装 · 选款与报价中台已启动
  监听: 0.0.0.0:8765
  本机打开： http://127.0.0.1:8765/index.html
  局域网/服务器访问： http://<这台机器的IP>:8765/index.html
  共享数据文件： /opt/xiaoman/data/store.json
```

**关键：`HOST=0.0.0.0` 不能省**，否则只有服务器自己能访问。

然后在浏览器打开 `http://服务器公网IP:8765/index.html`。

## 四、放行端口（很容易漏）

两个地方都要开：

1. **云厂商控制台的安全组**：入方向放行 TCP 8765（或你换成 80）
2. **服务器自身防火墙**：

```bash
# Ubuntu/Debian
ufw allow 8765/tcp && ufw reload

# CentOS
firewall-cmd --add-port=8765/tcp --permanent && firewall-cmd --reload
```

打开不通的话，先在服务器上 `curl -I http://127.0.0.1:8765/index.html` 确认服务活着，
再用手机流量访问公网 IP 排除公司网络限制。

---

## 五、做成开机自启（正式用必须做）

临时跑的那个窗口一关服务就没了。用 systemd 托管：

```bash
# 1. 复制配置（仓库里已经准备好；路径默认 /opt/xiaoman）
cp /opt/xiaoman/tools/deploy/xiaoman.service /etc/systemd/system/xiaoman.service

# 2. 改成你的实际路径与监听地址（直接对外访问要把 HOST 改成 0.0.0.0）
nano /etc/systemd/system/xiaoman.service

# 3. 启动并设为开机自启
systemctl daemon-reload
systemctl enable --now xiaoman

# 4. 看状态和日志
systemctl status xiaoman
tail -f /var/log/xiaoman.log
```

之后更新代码只需要：

```bash
cd /opt/xiaoman && git pull && systemctl restart xiaoman
```

## 六、用域名 / 加 HTTPS（可选）

没有域名也能用（`http://公网IP:8765`）。要用域名：

1. 域名解析 A 记录指向服务器 IP
2. **国内服务器必须先备案**，否则 80/443 会被拦
3. 装 nginx 反代，把 8765 收到内部：

```bash
apt install -y nginx
cp /opt/xiaoman/tools/deploy/nginx-xiaoman.conf /etc/nginx/conf.d/xiaoman.conf
nano /etc/nginx/conf.d/xiaoman.conf     # 把 server_name 改成你的域名；要密码就放开 auth_basic 三行
nginx -t && systemctl reload nginx

# HTTPS（自动续期）
apt install -y certbot python3-certbot-nginx
certbot --nginx -d your-domain.com
```

用 nginx 之后，systemd 里把 `HOST` 改回 `127.0.0.1`，8765 端口就可以在安全组里关掉。

## 七、数据和备份

**唯一需要备份的文件**：

```
/opt/xiaoman/data/store.json
```

里面是询价、报价、结算单、售后记录。建议每天定时打包：

```bash
# 每天 3 点备份，保留 14 天
cat >> /etc/crontab <<'EOF'
0 3 * * * root tar -czf /opt/backup/xiaoman-$(date +\%F).tar.gz -C /opt/xiaoman data && find /opt/backup -name 'xiaoman-*.tar.gz' -mtime +14 -delete
EOF
mkdir -p /opt/backup
```

要恢复：解开压缩包，把 `data/store.json` 放回原位，`systemctl restart xiaoman`。

## 八、安全提醒（重要）

目前的共享接口 `/api/store` **没有登录校验**——谁拿到网址，谁就能读、能写数据。
内部试用没问题，但如果放到公网，请至少做一层：

| 做法 | 说明 |
|---|---|
| **nginx 加密码**（最简单） | 上面配置文件里 auth_basic 那几行去掉注释，`htpasswd -c /etc/nginx/xiaoman.htpasswd xiaoman` 建账号 |
| **只让固定 IP 访问** | 安全组入方向限制来源 IP 为公司/家里出口 IP |
| **走内网 / VPN** | 服务器不暴露公网，用 Tailscale 之类的虚拟内网访问 |
| **换端口** | 8765 改成不常见端口，降低被扫到的概率（治标） |

另外注意：`/data` 和 `/tools` 目录已经被服务端禁止直接下载（里面有数据文件和 RedFox Key），
不要把它们单独再放进 nginx 静态目录。

> 客户在选码时会报孩子身高体重、联系方式，属于未成年人信息与个人信息。服务器上的 `data/store.json` 要限定可读范围，导出与备份文件不要随手发到群里。

## 九、上服务器之后行为有什么变化

| | 之前（各人本机） | 现在（服务器） |
|---|---|---|
| 客户提交的询价 | 只在那台电脑上 | 存服务器，员工任何电脑都能看到 |
| 员工发的报价 | 客户看不到 | 客户在自己的「收到的报价」里能看到 |
| 客户的结算记录 | 只在本机 | 存服务器，换电脑登录也还在 |
| 售后记录 | 老板/员工各一份 | 两边都能看到，删除仍互相独立 |
| 数据同步 | 同浏览器两个窗口实时 | 每 15 秒自动拉一次，切换页面也会拉 |

> 同一台电脑开两个窗口（一个员工一个客户）依然可用：登录身份按窗口存，
> 数据靠服务器互通，不再依赖浏览器内存。
