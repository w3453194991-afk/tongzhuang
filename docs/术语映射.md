## 核心术语

| 旧（汽配） | 新（童装） | 说明 |
|---|---|---|
| 车型 / 车系（vehicles） | 款式系列 | 例：奶油小方 · 圆领卫衣 |
| 车桥 / 桥型（axles） | 尺码段 | 例：110（3–4 岁，身高 105–115cm） |
| 型号 / 件号（products） | 款号 / SKU | 例：SW2601001 |
| 编码 / OE 号 / WVA / FMSI（codes） | 编号（款号 / 条码 EAN / 客户款号 / 旧款号 / 平台款号） | 编号类型：款号、内部款号、条码 EAN、客户款号、旧款号、竞品款号、平台款号 |
| 适配关系 / 适配（fitments） | 适穿关系 / 尺码适配 | 「款式系列 × 尺码段 → 款号」 |
| 适配图谱 | 尺码适配图谱 | |
| 材质 / 配方（materials） | 面料 | 精梳纯棉 / 莫代尔 / 摇粒绒 / 涤纶防水布 / 竹节棉 / 羊毛混纺 |
| 规格（dim） | 尺码 | 例：90–140cm |
| 孔数（holes） | 克重（g/m²） | 例：260 g/m² |
| 部位：前 / 后（pos） | 版型：宽松 / 标准 / 修身 | |
| 试验报告（tests） | 质检报告 | GB 31701-2015、GB 18401-2010、OEKO-TEX 100、起球、色牢度、缩水率 |
| 刹车片 / 鼓式衬片 / 盘式刹车片 / 制动蹄 | 童装品类：连衣裙 / 卫衣 / T恤 / 外套 / 裤装 / 套装 / 家居服 / 连体衣 | |
| 摩擦材料 / 摩擦系数 μ | 面料成分 / 克重 | |
| 装车 / 装车异常 / 退换索赔 | 试穿 / 尺码不合 / 退换与售后 | |
| 旧件（旧片） | 孩子现在穿的同类衣服 / 旧款 | |
| 拍旧片 + 卷尺 / 车桥铭牌 | 拍水洗标 + 量身高 / 平铺尺寸 | |
| 数孔数（8 / 12 / 15 / 16 孔） | 看水洗标尺码（90 / 110 / 4T）/ 量身高体重 | |
| 问桥不问车 | 问身高不问年龄 · 问尺码段不问「多大」 | |
| MOQ（套 / 片） | 起订量（件） | |
| 阶梯价档位 1000+ / 300+ / 100+ 套 | 1000+ / 300+ / 100+ 件 | |

| 风电制动块 / 离合器面片 / 其他配件 | 不适用，删掉 | |

## 典型句子改写示例

- 旧：「同车型不同车桥，装错就抖」→ 新：「同一系列不同尺码段，码错了就退」
- 旧：「先问车桥，别问车型，效率高 10 倍」→ 新：「先问身高，别问年龄，效率高 10 倍」
- 旧：「272 个型号 / 613 个编码 / 26 个车型 / 44 条适配」→ 新：「272 个款号 / 613 个编号 / 26 个款式系列 / 44 条适穿关系」
- 旧：「拍 3 张照：旧片正面 / 侧面带卷尺 / 车桥铭牌」→ 新：「拍 3 张照：孩子平铺的同款衣服 / 水洗标特写 / 身高对照门框」
- 旧：「试验报告 GB 5763 / ECE R90」→ 新：「质检报告 GB 31701 / GB 18401 / OEKO-TEX 100」
