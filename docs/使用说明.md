# 使用说明（给销售 / 外贸 / 报价岗）

> 不用装软件，不用记命令。双击 `启动.bat`，浏览器打开就能用。
> 界面支持 10 种语言（中 / 英 / 西 / 葡 / 阿 / 俄 / 印尼 / 越 / 泰 / 土），给客户的资料是中文 + 英文双语。
> 这份说明只讲童装一线会遇到的四件事：**怎么定码、怎么看水洗标、怎么选面料克重、资料包怎么发**。

---

## 1. 打开

1. 双击文件夹里的 **`启动.bat`**。
2. 浏览器自动打开 `http://127.0.0.1:8765/index.html`。
3. 服务在后台静默运行，没有黑窗口要留；要关服务双击 **`停止.bat`**。

打不开时：直接双击 `index.html` 也能用，但「资料包 ZIP 带图」和 RedFox 数据需要本地服务。

### 1.1 第一次打开会问你两件事

**先选界面语言**（10 种，选完记住；顶部右上角随时能换，阿拉伯语自动从右往左）。首页的示例句会跟着语言换成当地客户的说法，点一下就进选款。

**再登录**（登录窗默认只显示客户登录，员工 / 老板入口是隐藏的）：

| 你是谁 | 怎么登 | 登进去能看到 |
|---|---|---|
| **客户** | 选联系方式类型（WhatsApp / 手机 / 邮箱 / 微信 / Telegram / Viber），填号码或邮箱，再填称呼、公司、国家（可空） | 只能看选款、产品库、参考价，以及**属于他自己的**报价单和售后记录 |
| **体验版客户** | 什么都不用填，点一下「⚡ 体验版 · 客户」 | 直接进客户版，所有功能都能试；顶栏显示「体验版 · 客户」 |
| **员工** | **先在登录窗顶部（Logo + 标题那块）双击**解锁入口，再选「员工」，输入访问码 `XM2026`（`assets/auth.js` 顶部 `STAFF_CODE` 可改），填个名字 | 全部页签，外加**客户浏览**：客户搜了什么、看了哪些款、开没开报价单 |
| **体验版员工** | 双击解锁后点「⚡ 体验版 · 员工」，不用访问码 | **只读**：全部页签都能看，但发送、导入、保存报价、改数据都被挡住 |
| **老板 / 体验版老板** | 同样双击解锁，再选「老板」（老板码 `XMBOSS`）或点「⚡ 体验版 · 老板」 | 员工业绩、成交、转化与款式结构；登记类操作被禁用 |

客户用哪个联系方式登录，报价单就填他自己；员工生成资料包时按选中的客户填。员工点「发送」会直接拉起对应的 WhatsApp 或邮件。

> 访问码在 `assets/auth.js` 顶部（`STAFF_CODE` / `BOSS_CODE`）可改，改完把这里也改一下。
> 员工 / 老板入口只在本次打开期间解锁：**退出登录会自动收起**；要换身份，再双击一次登录窗顶部。

## 2. 最常用的一条路径（记住这四步）

```
输入客户原话  →  看候选款和依据  →  加入报价  →  生成报价单 / 资料包
```

顶部搜索框随便输入，回车：

- `奶油小方 圆领卫衣 110 码 300 件`
- `女童 碎花连衣裙 110 120 150 件`
- `婴童 连体衣 66-73 500 件`
- `云朵裙 110`（只报系列名 + 尺码段也行）
- `DR2601001` 或 `6972026112300`（只有一个款号 / 条码也行）
- `110 加绒卫衣`（尺码段 + 品类 + 面料诉求）
- 客户原话：`Necesitamos vestidos para niña de 4 años, 300 pzas`

**注意**：搜索框认的是**系列名 / 尺码段 / 款号 / 编号 / 品类词 / 面料词 / 数量**，不直接解析「105cm 17kg」。客户报身高体重时，用下面的「三步定码法」把它翻成尺码段（105cm → 100 或 110），再拿码段去搜。

**系统不猜。** 信息不够时它给的是「候选 2–3 个 + 一句该问客户的话」，不是硬塞一个款——这样报出去的价才收得回来。

## 4. 定码：客户给身高体重，怎么定

### 4.1 一条铁律

**按身高选码，年龄只做交叉验证；体重用来判断要不要上浮。**

- 客户说「4 岁」→ 只能初筛，必须追问身高。
- 客户说「穿 110」→ 问一句「是今年新买的 110，还是去年的？」童装一年差 8–10cm 很常见。
- 客户说「4T / 5T」→ 这是外单码，先换算成身高，再按下面的表走（见 §5.2）。

### 4.2 14 个尺码段总表

系统里就这 14 段（内部编号 `AX-xx` 只给系统看，报价和资料包都按标称写），报价、适穿关系、资料包全按这个口径：

| 尺码段 | 身高 | 体重 / 胸围 | 年龄参考 |
|---|---|---|---|
| 59–66 | 59–66cm | 4–6kg | 0–3 月（新生儿） |
| 66–73 | 66–73cm | 6–8kg | 3–6 月 |
| 73–80 | 73–80cm | 8–10kg | 6–9 月 |
| 80–86 | 80–86cm | 10–11kg | 9–12 月 |
| 86–92 | 86–92cm | 11–12.5kg | 12–18 月 |
| 92–98 | 92–98cm | 12.5–14kg | 18–24 月 |
| 90 | 85–95cm | 胸围 52cm | 1–2 岁 |
| 100 | 95–105cm | 胸围 54cm | 2–3 岁 |
| 110 | 105–115cm | 胸围 58cm | 3–4 岁 |
| 120 | 115–125cm | 胸围 62cm | 4–6 岁 |
| 130 | 125–135cm | 胸围 66cm | 6–7 岁 |
| 140 | 135–145cm | 胸围 70cm | 7–9 岁 |
| 150 | 145–155cm | 胸围 76cm | 9–11 岁 |
| 160 | 155–165cm | 胸围 82cm | 11–13 岁 |

**注意两套码表并存**：婴童是连续身高段（86–92、92–98），小童起是偶数码（90、100、110）。一个 92cm 的孩子同时落进「86–92」和「90」，这不是库乱，是两套标法都在用——按品类选其中一套即可。

### 4.3 五步定码法

1. **问净身高 + 体重**：不穿鞋、靠墙站，脚后跟 / 臀 / 肩胛贴墙；体重报公斤。
2. **身高落段**：在上表里找到覆盖他身高的段，通常会有 1–2 个候选。
3. **体重校验**：超过该段体重上限就往上走一码；偏瘦且款型宽松（版型标「宽松」）可以原码。
4. **品类修正**（见 4.5）：连体衣卡紧、外套放一档、裤装看腰围。
5. **交叉验证**：让他报「现在穿的同类衣服是什么码」，再拍一张衣服平铺图和一张水洗标照片。

### 4.4 三个算例

**例 1：女童 105cm / 17kg，幼儿园演出要连衣裙。**
105 正好是 100 码上限、110 码下限。演出款按净身高、**宁短不长**（拖地会踩），定 **110**；若孩子偏瘦、且客户要「能穿两季」，110 也是这一档里最稳的。系统里云朵泡泡系列覆盖 90–140cm，报 110 时在备注写「演出用，按净身高定码」。

**例 2：男童 88cm / 12kg，要加绒卫衣。**
88cm 同时落「86–92」和「90」。贴身 / 连体选 86–92；外穿卫衣选 90。若客户说「想穿到明年春天」，可以给 100，但要提前说清「袖子会明显长一截，得卷起来」。

**例 3：女童 128cm / 24kg，要裤装。**
身高落 130（125–135）。裤装光有身高不够——**系统里没有腰围表**，让客户把现在合身的裤子平铺，量一下腰围和裤长，报给你；差 2cm 以上就换码或改松紧。

### 4.5 品类修正表

| 品类 | 怎么修正 | 为什么 |
|---|---|---|
| 连体衣 / 爬服 | 按身高卡紧，不预留 | 抱起来会堆在腿根，大了反而勒 |
| 连衣裙 | 日常按身高；演出 / 礼服按净身高，宁短不长 | 拖地会踩、会脏，拍照也不好看 |
| 卫衣 / T恤 | 宽松版型可原码；修身版型按胸围 +4cm | 版型差异比码数差异大 |
| 外套 / 冲锋衣 / 羽绒 | **+1 档**给内搭 | 110 的孩子穿 120 外套很常见 |
| 裤装 | 身高定裤长，腰围定肥瘦 | 腰围数据要客户平铺量 |
| 套装 | 按上衣定码，裤子可单独换码 | 下单备注「上衣 110 / 裤 120」 |

### 4.6 系统里怎么用

1. 先把身高体重翻成尺码段（105cm → 100 或 110，见 §4.2），再在「智能选款」输入 `云朵裙 110 300 件` → 看**识别结果**（系列 / 尺码段 / 数量）和**候选款**。
2. 每个候选都有匹配分：**≥90 可直接报价 / ≥75 高置信，确认一次 / ≥58 必须先问清楚 / <58 转人工**。
3. 识别到款式系列时，下面会给**尺码段对应表**：一个系列可能覆盖 4–6 个码，让客户确认具体码。
4. 页面里的「**现场三步定码法**」卡片是给销售背的话术：**问身高不问年龄 → 拍三张照 → 看水洗标**。客户说不清款号时，直接复制发过去。
5. 适穿关系带置信度（高 / 中 / 低，**目前 0 条「已确认」**）。低置信度的款，大货报价前让版房复核；系统里的「待复核」队列就是干这个的。

## 5. 水洗标尺码怎么读

### 5.1 一张水洗标上有 6 行信息

| 行 | 内容 | 用途 |
|---|---|---|
| 1 | 品名 + **款号**（如 DR2601001） | 拿款号回系统查，最准 |
| 2 | **尺码**（90 / 110 / 4T / 92） | 判断是哪套码表 |
| 3 | 纤维成分及含量（如 95% 棉 5% 氨纶） | 判断面料、缩水与起球风险 |
| 4 | **安全类别**（GB 31701-2015 A 类 / B 类 / C 类） | 客户最常问的合规项 |
| 5 | 执行标准 / 洗涤符号 | 报价单和客诉时引用 |
| 6 | 产地 / 制造商 | 大货单据核对 |

### 5.2 尺码有三种写法，别混着算

| 写法 | 例子 | 说明 |
|---|---|---|
| 国标身高码 | 90 / 100 / 110 / 120 | 偶数码，对应身高区间（见 §4.2） |
| 婴童身高段 | 59–66 / 66–73 / 86–92 | 按月龄 + 身高，连体衣、爬服常见 |
| 外单码 | 2T / 3T / 4T、欧码 92 / 98 / 104、美码 2 / 3 / 4 | 不同客户、不同市场各一套 |

**换算原则：不按「T = 岁数」直接加。**

- 4T 与国标 110 相近，但**不等价**——系统在消歧问题里写得很直白：「水洗标上是 110 还是 4T？两个码表的实际尺寸差 2cm。」
- 系统为了好搜，把 `4T` 做成了 `110` 的搜索别名（搜 4T 会出 110 的款）；**但别把 4T 直接当 110 报价**，按客户实测身高体重再核一遍。
- 欧码 92 大致在国标 90 附近，98 靠 100，104 靠 110；边界款一律按实测尺码表，不按公式。
- 客户只报「4T」时，追问一句身高体重，比换算表可靠。

### 5.3 安全类别怎么答

- **A 类**：36 个月及以下的婴幼儿纺织产品（甲醛、pH、色牢度限值最严）。
- **B 类**：直接接触皮肤的产品（T恤、连衣裙、卫衣基本都在这一档）。
- **C 类**：非直接接触皮肤（外套面料层等）。
- 出口客户还会问 **OEKO-TEX Standard 100**、BSCI 验厂、GRS 再生涤纶（部分款）。

客户问「有没有检测报告」：库里共 **12 份**质检报告，覆盖 12 个款，项目包括甲醛、pH、可分解致癌芳香胺、绳带与附件安全、重金属、耐皂洗 / 耐摩擦 / 耐汗渍色牢度、起球、水洗尺寸变化率、标识。**没报告的款不要拿别的款的报告顶**，写「可提供同面料同工艺的检测报告」。

### 5.4 让客户拍三张

1. 孩子现在穿的**同款衣服平铺**（旁边放把尺，能看衣长）；
2. **水洗标特写**（款号和尺码要清楚）；
3. **身高对照**：孩子靠门框站直，拍全身，门框上做个记号。

三张到手，定码基本不会错；只有一张模糊照片时，先给候选 + 消歧问题，别直接报死码。

### 5.5 用「编号对照」反查

客户发来一串不知道是什么的码（条码 EAN、客户款号、旧款号、平台款号），进「编号对照」：

- 支持自家款号 / 条码 / 客户款号 / 旧款号 / 竞品款号 / 平台款号，613 条编号统一归一化；
- 命中后直接给：款号、品类、面料与克重、尺码段、编号别名、质检报告份数；
- 缺口提示会告诉你「这款没有检测报告 / 适穿待核」，并给一句只追问一件事的话术。

## 6. 面料克重怎么选

### 6.1 六种面料

| 面料 | 克重 | 手感 / 特点 | 适合做 | 价格系数 | 注意 |
|---|---|---|---|---|---|
| 精梳纯棉 | 180–240 g/m² | 亲肤、吸汗、不易起球 | 四季基础款、贴身层、婴幼儿 A 类 | 1.00 | 深色款看耐皂洗 / 耐摩擦色牢度 |
| 莫代尔 | 150–190 g/m² | 垂顺、凉感、柔软 | 夏款连衣裙、家居服、连体衣 | 1.18 | 比纯棉贵约 18%，易勾丝 |
| 摇粒绒 | 240–320 g/m² | 保暖、轻、快干 | 秋冬外套、加绒卫衣、家居服 | 1.12 | 静电与起球，认 GB/T 4802.1 报告 |
| 涤纶防水布 | 110–150 g/m² | 防泼水、防风、耐磨 | 冲锋衣、外套、户外裤 | 1.35 | 要无氟防泼水检测报告 |
| 竹节棉 | 160–200 g/m² | 透气、凉感、竹节纹理 | 夏季 T 恤、连衣裙、家居服 | 1.08 | 纹理每批有差异，写进确认单 |
| 羊毛混纺 | 260–340 g/m² | 保暖、挺括、高档 | 大衣、外套、礼盒款 | 1.55 | 只能干洗 / 羊毛档，客诉高发 |

> 克重是「每平方米多少克」，不是越厚越好。同一种面料，克重高 20g 手感就差一档，价格也跟着动。

### 6.2 选面料先问四件事

1. **什么季节、什么场景**：入园日常 / 演出 / 家居 / 户外 / 送礼，答案完全不同。
2. **是否贴身、孩子多大**：36 个月及以下优先 A 类精梳纯棉；贴身层别用涤纶。
3. **客户的价格带**：报价区间 $3.47–46.05/件，面料系数从 1.00 到 1.55，先对价格带再选料。
4. **客户怎么洗**：中东、东南亚很多客户直接机洗甩干，羊毛混纺和莫代尔要提前说明洗护，否则退货率上来。

### 6.3 克重与季节的对照

| 场景 | 建议克重 | 常见面料 |
|---|---|---|
| 盛夏 T 恤 / 连衣裙 | 150–200 g/m² | 莫代尔、竹节棉、薄纯棉 |
| 春夏防晒外套 | 110–150 g/m² | 涤纶防水布 |
| 四季园服 / 基础款 | 180–240 g/m² | 精梳纯棉 |
| 秋冬卫衣 / 外套 | 240–320 g/m² | 摇粒绒、加厚纯棉 |
| 大衣 / 礼盒款 | 260–340 g/m² | 羊毛混纺 |

### 6.4 五个常见坑

1. **摇粒绒克重高但起球**：克重不等于耐穿，先看起球报告（GB/T 4802.1）。
2. **涤纶防水布手感硬**：童装外套要加内衬，否则客户第一反应是「扎」。
3. **莫代尔尺寸稳定性差**：水洗尺寸变化率报告必看，报价时把报告里的实测缩水率写进条款，别只写「轻微缩水」。
4. **深色纯棉掉色**：耐皂洗、耐摩擦色牢度两项都要有数据，别只看「环保染料」四个字。
5. **羊毛混纺不能机洗**：报价单和吊牌都要标，不然一批货的利润全赔在客诉上。

### 6.5 报价里怎么体现

单价 = 基准价 × **面料系数** × 数量阶梯 × 客户等级 × 价格等级（详见 §7「报价单」）。
换面料会重算单价，报价单里改一下面料即可，不用手算。

## 7. 页签逐个说

### 工作台 / 首页

- 打开就是**官网样式**：顶部大海报轮播、关于小满、品类入口、工具入口、新闻、联系。
- 大图下面那条搜索框最常用：输入客户原话直接选款，比一层层点菜单快。
- 点「品类」任意一张卡（连衣裙 / 卫衣 / T恤 / 外套 / 裤装 / 套装 / 家居服 / 连体衣）→ 直接跳到产品库并筛好类。
- 再往下才是「现在该联系谁」「最近浏览」，以及可折叠的「为什么『问身高不问年龄』」——以奶油小方为例：一个系列、三个尺码段、三个款号。

### 智能选款（核心）

1. 输入 → 点「解析并选款」。
2. 看顶部**识别结果**：系统把你这句话拆成了款式系列 / 尺码段 / 款号 / 数量，并标出命中了什么。
3. 看**候选款**：每个都有匹配分和依据链（命中款号 / 命中系列 / 命中尺码段 / 文本相似）。
4. 看**还差一步就能锁定**：这就是你要问客户的那句话，直接复制发过去。
5. 识别到系列时，下面出现**尺码段对应表**：一个系列可能对应 4–6 个码，让客户确认具体码。

### 产品库

按款号 / 编号 / 名称搜，或按品类、品牌线、面料筛。
每行左边都有**缩略图**（272 个款全部有图；图片缺失时显示占位图，不会空白）。
表格列：款号、名称、常推款式系列、品类、尺码、面料、编号数、适穿条数、热度、参考价、成交数。
点任意一行看详情：款图、尺码段、版型、克重、编号对照、适穿关系、质检报告。
右上「导出 CSV」可给 IT 或做二次加工。

### 尺码适配图谱

左边款式系列树，展开看「系列 → 尺码段 → 款号」。
右边尺码段主数据 + **待复核队列**。
新增关系点右上按钮，填完保存 → 进入待复核，不会立刻对外生效。

### 报价单

1. 客户与条款：选客户（自动带出等级、付款方式、贸易术语）。
2. 明细：改数量、换面料，单价与金额自动重算。
3. 右侧看货值、运费估算、合计。
4. 右上两个按钮，**大的那个是「报价」，小的那个是「生成报价单」**：
   - **报价（大）**：逐个款改单价（系统已按阶梯价填好），实时算合计，可写备注（如「价格 30 天有效，FOB 上海」）→ 点「发给客户」。客户登录后在右下角「客服解答」里能看到这张报价单和金额。
   - **生成报价单（小）**：预览 → 打印 / 另存为 PDF，用于邮件或存档。
5. 客户端的报价页是「询价 + 生成报价单」，没有发价按钮——发价是员工的动作。

**报价口径（演示公式，真实价格表导入前不要对外承诺）：**

```
单价 = 基准价 × 面料系数 × 数量阶梯 × 客户等级 × 价格等级
数量阶梯：1–99 件 ×1.00 ｜ 100–299 件 ×0.94 ｜ 300–999 件 ×0.88 ｜ ≥1000 件 ×0.82
客户等级：A ×0.97 ｜ B ×1.00 ｜ C ×1.03
价格等级：大客户 ×0.95 ｜ 标准 ×1.00 ｜ 经济 ×0.96
面料系数：精梳纯棉 1.00 ｜ 莫代尔 1.18 ｜ 摇粒绒 1.12 ｜ 涤纶防水布 1.35 ｜ 竹节棉 1.08 ｜ 羊毛混纺 1.55
```

- MOQ 按款定（演示数据 50 / 100 / 150 / 200 件），低于 MOQ 要在报价备注里写清加价或拒单。
- 运费为**体积估算**（单箱 CBM × 件数 ÷ 40 × 120），正式报价以货代确认为准。
- 报价有效期系统默认 30 天；演出、开学季这种档期单，建议写明「以定金到账日期排产」。

### 资料包

见 §8，单独讲。

### 编号对照（员工端专属）

输入**自家款号 / 条码 EAN / 客户款号 / 旧款号 / 平台款号 / 竞品款号**，看它在现有资料里能对上谁：

- 命中按可信度排序（精确 100 / 前缀 78 / 尺码段 72 / 系列 66 / 模糊 50）。
- 每条给：编号、类型、面料、尺码段、编号别名、质检报告份数。
- **缺口提示**：没检测报告 / 适穿待核 / 尺码表缺项 → 直接给「只追问一句」的话术。
- 「加入报价」直接进报价篮，不用跳回产品库。

> 这张表就是童装的「身份翻译表」：自家款号 ↔ 条码 ↔ 客户款号 ↔ 旧款号 ↔ 尺码段 ↔ 检测报告 ↔ 款图。表越全，客户拿自己的货号就能搜到你。

### 客户浏览（员工端专属）

客户的每一次登录、搜索、看款、加报价、开资料包都会记下来。这一页告诉你**谁在真正选款、谁只是路过**：

- 顶部四个数：24 小时内活跃、累计浏览款、打开报价 / 资料包的次数、高意向待跟。
- 列表按最近活跃排序，点一行看：他搜过的原话、看过的款、按天分组的轨迹。
- 下面有写好的消息框，点「用 WhatsApp 发送 / 用邮件发送」直接拉起客户端。
- 「加入询盘池」把这个人一键变成线索，评分和搜索词一起带过去。

> 记录存在本机（同一台电脑、同一个浏览器）。要客户在他手机上浏览、你在办公室看到，把服务端放到内网（见 `docs/部署到服务器.md`）。

### 客户询价（员工端专属）

客户在客户端点「询价」提交的清单会出现在这里：

- 每行：时间、客户（体验账号有黄色 `体验` 标签）、询价号、要的款号和数量、留言、联系方式。
- 「载入报价」→ 直接进报价单，改价、加运费、生成 PDF，一步不用重录。
- 「履历」→ 看这个客户之前搜过什么、看过哪些款。

### 增加客户（员工端专属）

- **手动录入**：姓名\*、公司、国家、联系方式类型 + 号码\*、标签、备注 → 保存。
- **拍照名片**：手机端点「拍照」直接调相机（桌面可上传）→ 预览 → 识别 → 自动带出姓名 / 公司 / 国家 / 联系方式 → 核对后保存。
- 联系方式按号码 / 邮箱归一化比对：已存在的客户会**更新**，不会建重复档案。
- 保存后立刻出现在「客户浏览」和客户列表里，可一键发 WhatsApp / 邮件、加入询盘池。

> 名片识别目前是演示数据：没接 OCR，点「识别名片」会填一组可改的示例字段。

### 询盘线索

- 列表按评分排序：终端属性加分、贸易商特征扣分，评分依据点开就能看。
- 「当地时间」列告诉你现在能不能联系。
- 点一行看详情：原文、中文摘要、自动匹配的款、状态和下一步。
- 「生成回复」按客户询盘自动填好，复制即用。

**止损线**：名字带 Trading / Import & Export / FZE 且拿不出终端门店或连锁信息的，只发目录；只问价不给品类、尺码、数量的，报价即可，不做方案。

### 用户画像（获客总入口）

进去顶部一条分段条：**用户画像 ｜ 客户搜索 ｜ 获客内容**，点一下互切。

- **用户画像**：关系网图 + 按意向度排序的账号列表；画像卡里有「常推品类 / 尺码段 → 可推款号」和推荐动作（寄样 / 私信 / 视频置换）；「生成私信」按该账号市场语种出草稿。
- **客户搜索**：按「产品词 + 客户类型 + 国家 / 语言」生成可直接投喂搜索引擎的检索式；客户类型选母婴连锁 / 买手店 / 电商 / 进口商 / 批发商；每条附 Google / Bing / Yandex 按钮（部分带 Maps / DDG），点开即搜。
- **获客内容**：热门视频雷达（哪个语种、什么选题、为什么火、能挂哪个款号）→ 点「用此选题」出 6 个分镜 + 目标语种口播 + 标签 + 拍摄清单 → 复制 AI 提示词去 Kling AI 出片或让大模型润色。

### 成交台账（员工端）

状态五档：**待报价 → 已报价 → 谈判中 → 已成交 / 已丢单**。

- 顶部四个数：本月成交额、成交单数、平均单额、在谈金额（只算你自己名下）。
- 「登记一笔」：选客户 → 填款号（自动带单价）→ 数量 → 金额自动算 → 选状态 → 存。
- 点表格任意一行看这一单的完整信息：客户、三个大数字、进度条、这个客户的其他记录、这个款号还卖给过谁。
- 产品库多了一列「成交」：这个款成了几单，一眼看出哪些在走量。

### 热门追踪 · RedFox（员工端）

把 [redfox.hk](https://redfox.hk/skills) 的短视频数据技能接进来，给「用户画像 · 获客内容」和「询盘线索」供料。

3. 选平台 → 选技能 → 填参数 → 运行 → 结果可「把作者导入线索」「存为选题」。

支持 11 个平台（TikTok / Instagram / YouTube / X / 抖音 / 小红书 / 公众号 / 快手 / 视频号 / B站 / 今日头条）。按调用次数计费（参考 ¥0.02–0.06/次），没有 Key 时页面给引导，不报错。

试穿不合、尺码换货、退换与索赔都在这里登记；员工看全量，客户只看自己提交的那几条。登记时把**款号 + 尺码段 + 问题类型（试穿异常 / 尺寸不符 / 退换 / 索赔）+ 问题描述 + 照片**填全，后面复盘尺码表就靠这批数据。

## 8. 资料包怎么发

### 8.1 什么时候发

1. 客户问「有没有目录 / 资料 / 检测报告」——**当场发**，别等。
2. 报完价 30 分钟内——报价单 + 资料包一起发，客户不用来回问。
3. 大货下单前——用「发货前确认页」把尺码、颜色、面料、包装一次性确认掉。

### 8.2 怎么生成

报价单里勾好款 → 切到「资料包」→ 勾选要打包的内容 → 点「生成并打印」（多页 A4）或「下载 ZIP」。

- **打印**：浏览器打印里选「另存为 PDF」，见 §10。
- **ZIP**：`报价单.html` + `产品规格.csv` + `编号对照.csv` + `适穿关系.csv` + `产品数据页.html` + `img/` 款图，体积小，适合 WhatsApp / 微信直接发。
- ZIP 带图需要本地服务：通过 `http://127.0.0.1:8765/index.html` 打开；直接双击 `index.html`（`file://`）时图片取不到，只能用打印版。

### 8.3 里面有什么（逐页）

| 页 | 内容 | 客户拿它干什么 |
|---|---|---|
| 封面 | 客户名、国家、资料编号、日期、款号清单、公司信息与认证 | 归档、内部传阅 |
| 报价单 | 条款、阶梯价、运费估算、合计、有效期 30 天 | 比价、审批 |
| 每款一页 | 款图、款号、品类、版型、尺码、面料与克重、包装（件/袋、箱规、毛重、CBM）、HS、MOQ；下半页是编号对照、适穿关系、质检摘要 | 选款、对尺码、算运费 |
| 质检摘要 | 有报告的款才出（12 份报告覆盖 12 个款），列标准、项目、结论、实验室、报告号 | 合规审核 |
| 确认页 | 逐款列出 3 条待确认：适穿关系里的消歧问题 +「平铺尺寸（胸围 × 衣长）是否与资料页一致」+「水洗标尺码或孩子身高是否已确认」，带签字栏 | 大货前定版，避免错码 |

### 8.4 发之前 6 项自检

1. **客户名 / 国家**对不对（资料包按你选中的客户填，手动改过要再看一眼）。
2. **款号**和客户确认的是不是同一个（别把相似款混进去）。
3. **尺码段**写清楚：是「系列覆盖 90–140」还是「这次只报 110」。
4. **质检报告**是不是这款的（只有 12 个款有报告；没有就写「可提供同面料同工艺报告」，别顶替）。
5. **价格有效期与运费口径**写清楚（30 天 / FOB 上海 / 运费为估算）。
6. **适穿置信度低的款**，资料包里不要出现「保证合身」这类承诺，改成「建议按身高体重复核」。

### 8.5 三条发送路径

| 场景 | 发什么 | 怎么发 |
|---|---|---|
| 正式报价 / 邮件 | 打印版 PDF | 打印 → 另存为 PDF → 邮件附件 |
| WhatsApp / 微信快速发 | ZIP | 下载 ZIP → 直接拖进聊天窗口 |
| 客户在手机上急着看 | 报价单截图 + 款图 | 截图发过去，PDF 后补 |

命名建议：`小满童装_客户名_20261123_3款.pdf`，客户存下来三个月后还找得到。

### 8.6 不要发的东西

- 内部成本、别人的报价、客户浏览记录；
- 未复核的适穿关系当承诺；
- 别的款的检测报告；
- 带过期品牌字头或旧日期的模板（发之前看一眼封面）。

## 9. 右下角「客服解答」

**客户看到的**（问答式）
- 一句「需要什么帮助？」+ 两个示例问题（`奶油小方 圆领卫衣 110码 300件` / `110 码 卫衣 200 件`），点一下直接问。
- 底部有输入框：直接打身高、尺码或问题，回车发送。

- 会话记录存在浏览器里，刷新不丢。

**员工看到的**（聊天雷达）
- 点「模拟新消息」，看一条阿语 / 西语 / 印尼语询盘进来，1 秒内弹出「款式 → 款号 → 价格」。

- 没命中，自动给「三步定码法」索要照片的话术。

> 交期口径目前有两套：浮窗写「现货 3–7 天，改色 / 换面料 / 换标 15–25 天」，报价单页脚写「定金后 25–35 天」。对外报之前，按公司当月的真实排产统一成一条。

## 13. 常见问题

**Q：客户只说「4 岁」，怎么办？**
A：回一句「孩子净身高多少？按身高选比按年龄准」。4 岁通常在 100–110 之间，但差 10cm 就是两个码。

**Q：客户说「和去年一样的码」，能直接报吗？**
A：不能。让他拍水洗标或报款号——同一年龄不同品牌差 1–2 码很常见，去年的 110 今年可能只够当短款。

**Q：4T 和 110 一样吗？**
A：相近但不等价，系统里明确提示两套码表实测差 2cm。按身高体重定，别按「T = 岁数」。

**Q：搜「110」出来几十个款，是不是不准？**
A：110 是尺码段不是款号，同码段本来就有几十个款。先按品类或场景（演出 / 入园 / 家居）收窄，再确认面料和颜色。

**Q：演出连衣裙报 110 会不会短？**
A：演出款按净身高、宁短不长；要留长一季就报 120，但要提前说清「肩线和腰线会下移」。

**Q：为什么有的款没有质检报告？**
A：库里只有 12 份，覆盖 12 个款。其余款发资料时写「可提供同面料同工艺的检测报告」，不要拿别的款的报告顶。

**Q：报价和公司实际价格不一致？**
A：现在库里的价格是演示基准价。让报价岗把真实价格表整理成 CSV，在「数据导入」里选「产品更新」导入即可。

**Q：资料包里的图打不开？**
A：图片在本机 `assets/img/p/` 里。用「打印 → 另存 PDF」会带图；ZIP 里的图需要从 `http://127.0.0.1:8765` 打开页面再下载。

**Q：能不能只给某个客户看某几个款？**
A：可以。加入报价时只加那几个，再生成资料包即可。

**Q：客户要加急，演出档期赶得上吗？**
A：现货款 3–7 天，改色 / 换面料 / 换标 15–25 天（演示口径，以当月排产为准）。演出单建议倒推：确认样 → 大货 → 海运 / 空运，把交期写进报价备注，别口头承诺。
